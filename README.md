# jeonghwan365.github.io

황정환의 포트폴리오 사이트입니다. https://jeonghwan365.github.io

2023년 12월부터의 경험을 트랙별 가로 타임라인과 기록 목록으로 보여 줍니다.

## 구성

- **머리**: 이름, 지원 분야, 한 줄 소개, 학력과 병역
- **타임라인**: 학업·어학, 실무 경험, 프로젝트·수상, 교내 활동 네 트랙 위에 경험을 시간순으로 배치한 도표. 빨간 세로선이 오늘이고, 빗금은 앞으로의 기간입니다. 항목을 누르면 해당 기록으로 이동합니다.
- **기록**: 모든 경험의 목록. 누르면 그 자리에서 펼쳐지고, 보고서 원문도 펼쳐 볼 수 있습니다.

## 만든 방법

Claude Code와 함께 기획하고 만들었습니다. 내용은 `data.js` 하나에 모여 있고, 화면은 빌드 도구 없이 HTML·CSS·JavaScript로 그립니다. 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.

```
├── index.html   페이지 뼈대
├── style.css    색, 글꼴, 배치
├── app.js       data.js를 읽어 화면을 그리는 코드
├── data.js      모든 내용
└── files/       첨부 파일
```

## 내용 수정

`data.js`의 `items` 배열에 항목을 시간순으로 추가합니다. 형식은 CLAUDE.md에 있습니다.
